# Prof. Yogendra K — Academic Website

This is a responsive, static academic portfolio website designed for GitHub Pages. It does not require programming knowledge, a database, or a paid hosting plan.

## Files included
- `index.html` — website content
- `styles.css` — layout, typography and visual design
- `script.js` — mobile navigation and current year
- `assets/leaf-mark.svg` — browser tab icon

## Before publishing: 5-minute personalisation checklist
Open `index.html` in any text editor and make these updates:

1. **Official email:** Find `ADD OFFICIAL EMAIL` and replace it with your verified institutional email address.
2. **Academic profiles:** Replace the generic Google Scholar, ORCID and ResearchGate platform links with your personal profile URLs.
3. **Profile statistics:** Check the publication, citation, h-index and supervision figures. The figures currently shown are based on profile information compiled in 2026 and should be verified before public use.
4. **Publications:** Verify article titles, author order, journal details, volume/issue, page or article number, and DOI. Add DOI links where available.
5. **Photograph (optional):** This design currently uses a typographic monogram and illustrated Western Ghats-inspired landscape, so it works without a photograph. If you want a photograph, add it in a later revision.

Use your text editor's Find feature to locate the exact text. Do not change file names or move the files out of their folders.

## Publish on GitHub Pages — no coding required

### A. Create your website repository
1. Sign in to GitHub or create an account at https://github.com/.
2. Click **New repository**.
3. Name the repository exactly `YOUR-GITHUB-USERNAME.github.io` (replace `YOUR-GITHUB-USERNAME` with your GitHub username).
4. Set the repository to **Public** and create it.

### B. Upload the website
1. Open the new repository.
2. Choose **Add file → Upload files**.
3. Unzip this package on your computer first.
4. Upload `index.html`, `styles.css`, `script.js`, `README.md`, and the `assets` folder with its SVG file. Upload the contents of the website folder, not the ZIP itself.
5. Enter a commit message such as `Add academic portfolio website` and click **Commit changes**.

### C. Enable / check GitHub Pages
1. In the repository, open **Settings → Pages**.
2. Under Build and deployment, choose **Deploy from a branch**.
3. Select branch `main` and folder `/ (root)`, then save if required.
4. Wait a few minutes and open `https://YOUR-GITHUB-USERNAME.github.io/`.

GitHub's interface can change slightly. If the site does not appear immediately, wait a few minutes and check the Pages section for the deployment status.

## Notes
- The website is mobile responsive and includes a collapsible mobile menu.
- No tracking scripts, forms that collect personal information, or third-party analytics are included.
- Google Fonts are loaded online; if unavailable, the page falls back to system fonts.
- This package is a static site. The contact section displays your official email once you replace the placeholder; it does not submit a contact form.
- Review institutional titles, partner names, publication records and all personal details before making the website public.
